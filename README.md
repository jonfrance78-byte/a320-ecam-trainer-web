# A320 ECAM Trainer (web)

Public build of the A320 ECAM Trainer flight deck shell, served at
https://jonfrance78-byte.github.io/a320-ecam-trainer-web/ . The files here are
generated from a private source repository; don't edit them here.

Training aid only: not a substitute for the FCOM, QRH, FCTM or your operator's procedures.
